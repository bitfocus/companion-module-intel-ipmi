Pixera IPMI

Import & usage — power a server on and off from Companion

Module for Bitfocus Companion 4  •  version 1.0.0  •  developed by LTT-DEV

English  •  Polski →

What it is for. This module lets you switch a Pixera server's power on and off straight from Companion buttons — just like pressing the power button on the chassis, only remotely. It works alongside the regular “AV Stumpfl: Pixera” module, which controls the program itself. In short: that module controls the application, this one controls the power.

1. Before you start

  • You have Bitfocus Companion 4 installed.
  • You have the module file: avstumpfl-pixera-ipmi-1.0.0.tgz.
  • The Companion computer can see the server on the network — i.e. it is connected to the same management network as the IPMI/BMC port of the Pixera server.
  • You know the IP address, username and password of the server's management panel (BMC).

2. Install the module in Companion

  1. Open Companion in a browser (usually http://127.0.0.1:8000).
  2. Go to the Modules tab.
  3. Click Import and point it at avstumpfl-pixera-ipmi-1.0.0.tgz.
  4. The module list will show “AV Stumpfl: Pixera IPMI”. Done.
It is a separate module — it does not mix with the regular Pixera module. You can safely use both at once.
Updating: if you already have an older version of this module, uninstall it first, then import the new one — otherwise Companion rejects the import.

3. Add a connection to the server

  1. Go to Connections → Add connection.
  2. Search for “Pixera IPMI” and pick AV Stumpfl: Pixera IPMI.
  3. Fill in the fields (see the table below) and save.
  4. The connection status should turn green / OK. That means the module is talking to the server and can see whether it is on or off.

What to enter in the fields

Field What to enter
BMC IP / Hostname The IP address of the server's management panel. The address only — no port, no spaces.
IPMI Username Login to the server panel (factory default is usually ADMIN).
IPMI Password Password to the server panel. (Or leave it blank and enter the sticker address in the field below — see box.)
LAN1 sticker IP Optional. The address from the sticker on the server — the module derives the factory password from it.
Other fields Leave them as they are (defaults match Pixera servers).
Don't know the password? Pixera servers have a factory password derived from the address printed on the sticker. Enter that address in the LAN1 sticker IP field, leave the password blank — the module fills the password in for you.
Note: if someone changed the password after the server was set up, the factory one no longer works — enter the current one manually then.

Example — factory settings

Field Value
BMC IP / Hostname 10.41.98.252
IPMI Username ADMIN
IPMI Password blank
LAN1 sticker IP 10.31.98.252

This is a neutral example showing the relation LAN1 10.31.x.x → BMC 10.41.x.x.

4. Place buttons and control

The easiest way is to use the ready-made buttons. In the button editor open the Presets list, choose the IPMI Power category and drag a ready button onto the grid. The button works right away and changes colour by itself depending on the server's state.

Available actions

Button What it does
Power On Turns the server on.
Restart (soft) Safely shuts the system down, waits until it is fully off, and powers it back on. Safest for a media server.
Soft Shutdown Graceful system shutdown (like “Shut down” in Windows).
Power Cycle Turns off and immediately back on.
Hard Reset Hard reset — without shutting the system down. Only when the server has frozen.
Power Down Hard power cut — like pulling the plug. Last resort.
Protection against mistakes. Actions that could kill a show (Soft Shutdown, Hard Reset, Power Down) only fire after a long press of the button — an accidental tap does nothing.

Button colours

  • Green — server on.
  • Red — server off.
  • Yellow — server unreachable (no contact — see troubleshooting).

5. Something not working?

Symptom What to do
Button / status is yellow (unreachable) The Companion computer has no contact with the server. Check that both are on the same management network and that the IP address is correct.
Login / password error Check the server panel login and password. If the password was changed after setup, the factory one no longer works.
The address “won't save” Enter just the IP address — no port and no spaces.
Soft Shutdown does not turn the server off Some servers do not support graceful shutdown — use Power Cycle or Hard Reset instead.
The module did not appear after import Uninstall the old version, import again and restart Companion.

6. Good practices

  • Keep server management on a separate, isolated network — never expose it publicly to the internet.
  • After setting up the server, change the factory password to your own.
  • For everyday use, use the Restart (soft) button — it is the gentlest for the server.

Pixera IPMI

Instrukcja obsługi — włączanie i wyłączanie serwera z poziomu Companion

Moduł do Bitfocus Companion 4  •  wersja 1.0.0  •  opracowane przez LTT-DEV

← English  •  Polski

Do czego to służy. Ten moduł pozwala włączać i wyłączać zasilanie serwera Pixera prosto z przycisków Companion — tak samo jakbyś nacisnął przycisk power na obudowie, tylko zdalnie. Działa obok zwykłego modułu „AV Stumpfl: Pixera”, który steruje samym programem. W skrócie: tamten moduł steruje aplikacją, ten steruje prądem.

1. Zanim zaczniesz

  • Masz zainstalowane Bitfocus Companion 4.
  • Masz plik modułu: avstumpfl-pixera-ipmi-1.0.0.tgz.
  • Komputer z Companion widzi serwer w sieci — czyli jest podłączony do tej samej sieci zarządzania co gniazdo IPMI/BMC serwera Pixera.
  • Znasz adres IP, login i hasło do panelu zarządzania (BMC) serwera.

2. Zainstaluj moduł w Companion

  1. Otwórz Companion w przeglądarce (zwykle http://127.0.0.1:8000).
  2. Wejdź w zakładkę Modules.
  3. Kliknij Import i wskaż plik avstumpfl-pixera-ipmi-1.0.0.tgz.
  4. Na liście modułów pojawi się „AV Stumpfl: Pixera IPMI”. Gotowe.
To osobny moduł — nie miesza się ze zwykłym modułem Pixera. Możesz spokojnie używać obu naraz.
Aktualizacja: jeśli masz już starszą wersję tego modułu, najpierw ją odinstaluj, a potem zaimportuj nową — inaczej Companion odrzuci import.

3. Dodaj połączenie z serwerem

  1. Wejdź w zakładkę Connections → Add connection.
  2. Wpisz w wyszukiwarce „Pixera IPMI” i wybierz AV Stumpfl: Pixera IPMI.
  3. Uzupełnij pola (patrz tabela niżej) i zapisz.
  4. Status połączenia powinien zrobić się zielony / OK. To znaczy, że moduł dogadał się z serwerem i widzi, czy jest włączony, czy wyłączony.

Co wpisać w polach

Pole Co wpisać
BMC IP / Hostname Adres IP panelu zarządzania serwera. Sam adres — bez portu i bez spacji.
IPMI Username Login do panelu serwera (fabrycznie zwykle ADMIN).
IPMI Password Hasło do panelu serwera. (Albo zostaw puste i podaj adres z naklejki w polu niżej — patrz ramka.)
LAN1 sticker IP Opcjonalnie. Adres z naklejki na serwerze — moduł sam wyliczy z niego fabryczne hasło.
Pozostałe pola Zostaw tak jak są (ustawienia domyślne pasują do serwerów Pixera).
Nie znasz hasła? Serwery Pixera mają fabryczne hasło wyliczone z adresu wydrukowanego na naklejce. Wpisz ten adres w pole LAN1 sticker IP, zostaw hasło puste — moduł podstawi hasło sam.
Uwaga: jeśli ktoś zmienił hasło po instalacji serwera, fabryczne już nie zadziała — wpisz wtedy aktualne ręcznie.

Przykład — ustawienia fabryczne

Pole Wartość
BMC IP / Hostname 10.41.98.252
IPMI Username ADMIN
IPMI Password puste
LAN1 sticker IP 10.31.98.252

To neutralny przykład pokazujący relację LAN1 10.31.x.x → BMC 10.41.x.x.

4. Postaw przyciski i steruj

Najprościej skorzystać z gotowych przycisków. W edytorze przycisków otwórz listę Presets, wybierz kategorię IPMI Power i przeciągnij gotowy przycisk na planszę. Przycisk od razu działa i sam zmienia kolor zależnie od stanu serwera.

Dostępne akcje

Przycisk Co robi
Power On Włącza serwer.
Restart (soft) Bezpiecznie wyłącza system, czeka aż całkiem zgaśnie, i włącza z powrotem. Najbezpieczniejsze dla media serwera.
Soft Shutdown Łagodne wyłączenie systemu (jak „Zamknij system” w Windows).
Power Cycle Wyłącza i od razu włącza ponownie.
Hard Reset Twardy reset — bez zamykania systemu. Tylko gdy serwer się zawiesił.
Power Down Twarde odcięcie prądu — jak wyrwanie wtyczki. Ostateczność.
Zabezpieczenie przed pomyłką. Akcje, które mogą ubić show (Soft Shutdown, Hard Reset, Power Down) odpalają się dopiero po dłuższym przytrzymaniu przycisku — przypadkowe muśnięcie nic nie zrobi.

Kolory przycisku

  • Zielony — serwer włączony.
  • Czerwony — serwer wyłączony.
  • Żółty — serwer nieosiągalny (nie ma kontaktu — patrz rozwiązywanie problemów).

5. Coś nie działa?

Objaw Co zrobić
Przycisk / status świeci na żółto (nieosiągalny) Komputer z Companion nie ma kontaktu z serwerem. Sprawdź, czy oba są w tej samej sieci zarządzania i czy adres IP jest poprawny.
Błąd logowania / hasła Sprawdź login i hasło do panelu serwera. Jeśli zmieniano hasło po instalacji, fabryczne już nie działa.
Adres „nie chce się zapisać” Wpisz sam adres IP — bez portu i bez spacji.
Soft Shutdown nie wyłącza serwera Niektóre serwery nie wspierają łagodnego wyłączenia — użyj wtedy Power Cycle lub Hard Reset.
Moduł nie pojawił się po imporcie Odinstaluj starą wersję, zaimportuj ponownie i zrestartuj Companion.

6. Dobre praktyki

  • Trzymaj zarządzanie serwerem w osobnej, odseparowanej sieci — nigdy nie wystawiaj go publicznie do internetu.
  • Po instalacji serwera zmień fabryczne hasło na własne.
  • Do codziennej obsługi używaj przycisku Restart (soft) — jest najłagodniejszy dla serwera.
